**これは何か**：太郎の脳の部位と、その呼び名。
§0（呼称）が**呼び方の唯一の決まり**で、§1以降は構造の記録。

## 0. 呼称（2026-09-15 決定・**これ以外の呼び方をしない**）

compact のたびに呼び方が変わって混乱したため固定した。**説明のための比喩は使ってよいが、
識別子としてはこの列の名前だけを使う。**

| 呼び名 | コード上の名前 | 人間側 | 何をするか |
|---|---|---|---|
| **本体GRU** | `brain` / `TaroBrain` | 感覚運動皮質＋運動野 | 463,931個。**うち言語は10,320個（2%）だけ**。残りは世界の予測器・運動野・感覚運動予測・視覚予測。言語では**切れ目の発見**（`end_probs`）と**発音**（`generate`）を担う |
| **塊GRU** | `chunk_brain` | 側頭葉（語の並び） | 81,386個。**どの語を言うか**だけを決める |
| **言語海馬** | `language_hippocampus` | 内側側頭葉 | 見え＋語を1件ずつ焼き付ける。**記憶の寿命は約500歩** |
| **分節** | いまは `lexicon.observe` の中 | 側頭葉（統計的分節・Saffran 1996） | 音の列を語の塊に切る |
| **塊の名簿** | `chunk_vocab` | — | 切り出された塊のID表。いま13個 |
| **意味の表** | `lexicon.proto` | — | 語ごとの見えの平均。**使われていない・削除予定** |
| **逆引き** | `lexicon.reverse_lookup` | — | 見えから語を引く。**使われていない・削除予定** |

**語を選ぶ経路（2026-09-02以降）**：

```
本体GRU：切れ目を見つける → 塊GRU  ┐ 自信の高い方を言う → 本体GRU：口を動かす
                            言語海馬 ┘   （0.5未満は黙る）
```
意味の表・逆引きは**この経路に入っていない**（`produce.word_choice: "gru_hippo"`）。

**使わない呼び方**：

- **A・B・C・D**（2026-09-14 に付けた記号。意味が伝わらないので廃止）
- **「音レベルGRU」** → 本体GRU と呼ぶ（言語は2%なので誤解を招く）
- 「速い器／遅い器」「写真アルバム／描けるようになった絵」は**説明の比喩としてはよい**が、
  どのファイルの話かを指すときには使わない

## 3. 「神経回路」か「表引き」か（2026-08-30 に判明）

**人間の脳はすべてが神経回路で、表は存在しない。** 太郎は大半が表引きになっている。

| 機能 | 人間 | 太郎 | 実体 |
|---|---|---|---|
| 視覚 | 神経回路 | **ネットワーク** | DINOv2（既製・固定） |
| 語彙の選択 | 神経回路 | 表引き | 語ごとの「見えの平均」とのコサイン |
| 発話の計画 | 神経回路 | ルール | 語をひらがなに分ける |
| 音と口の対応 | 神経回路 | 表引き | 喃語で作った帳面（68音） |
| 発話の実行 | 神経回路 | **ネットワーク**（ただし出力が捨てられる） | GRU。帳面に音があれば上書きされる |
| 発声 | 筋肉 | 変換表 | 4パラメータ → ひらがな |

**帰結**：表引きは干渉も忘却もしないので**間違えない**。
人間の12ヶ月児は初語の約33%を間違った物に使うのに、太郎は3語で100%正解する。
この「良すぎる」現象の根本原因は、学習の中身が**重みではなく記録と平均**であること。

## 4. 無い部位（2026-08-30時点）

| 部位 | 何をするはず | 無いことの影響 |
|---|---|---|
| **前頭前野** | 言うかどうかの判断・抑制 | 条件が揃うと必ず発話する＝反射的。ただし人間も12ヶ月では抑制課題の正答率が54%（ほぼ偶然）なので、月齢としては不自然ではない |
| **視覚野** | 見えから物を認識する | DINOv2 で代用。太郎の経験では育たない（逸脱リスト その23） |
| 運動前野 | 動作の準備 | 未検討 |
| 頭頂葉の一部 | 空間の把握 | 未検討 |

## 5. あるが使われていないもの

| もの | 状態 |
|---|---|
| GRU の隠れ状態（文脈） | 発話のたびに `hidden=None` でリセット。文脈が残らない |
| GRU の行動生成 | 体が固定（座位・pin_joints）なので出番がない |
| 周辺視 | 視線を動かすためだけ。意味の判断に使っていない |
| 右目 | 2026-08-30 に認識を片目にした（両目と成績が同じだったため） |
| 恒常性の報酬 | `body/homeostasis.py` にあるが脳から呼ばれていない（呼び出し0件） |
| 目標指向の探索 | `goal_babbling/` にあるが既定OFF（「現状は有害と判明」） |

## 6. 移行のときの注意

- **import が壊れる**。`from brain.lexicon import ...` のような参照が各所にある
- 移動は1つずつ行い、その都度 `run/main.py` が起動するか確認する
- `taro_brain.py` は名前を変えると影響が大きい（チェックポイントの復元にも関わる）
- **モデルの保存・復元と噛み合うか**を必ず確認する（クラス名や属性名が変わると
  既存の `.pt` が読めなくなる可能性がある）
