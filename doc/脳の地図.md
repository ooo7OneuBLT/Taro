# 太郎の脳の地図

**これは何か**：太郎の脳を構成するファイルを、人間の脳の部位に対応させた一覧。
「どこに何があるか」「何が無いか」「どこが神経回路でどこが表引きか」を1枚で見るためのもの。

作成：2026-08-30。きっかけはユーザーの指摘「GRU＝大脳皮質じゃなくて、大脳皮質という
フォルダの下にGRUのファイルがあるのが正しいのでは」。

## 3. 「神経回路」か「表引き」か（2026-08-30 に判明）

**人間の脳はすべてが神経回路で、表は存在しない。** 太郎は大半が表引きになっている。

| 機能 | 人間 | 太郎 | 実体 |
|---|---|---|---|
| 視覚 | 神経回路 | **ネットワーク** | DINOv2（既製・固定） |
| 語彙の選択 | 神経回路 | 表引き | 語ごとの「見えの平均」とのコサイン |
| 発話の計画 | 神経回路 | ルール | 語をひらがなに分ける |
| 音と口の対応 | 神経回路 | 表引き | 喃語で作った帳面（68音） |
| 発話の実行 | 神経回路 | **ネットワーク**（ただし出力が捨てられる） | GRU。帳面に音があれば上書きされる |
| 発声 | 筋肉 | 変換表 | 4パラメータ → ひらがな |

**帰結**：表引きは干渉も忘却もしないので**間違えない**。
人間の12ヶ月児は初語の約33%を間違った物に使うのに、太郎は3語で100%正解する。
この「良すぎる」現象の根本原因は、学習の中身が**重みではなく記録と平均**であること。

## 4. 無い部位（2026-08-30時点）

| 部位 | 何をするはず | 無いことの影響 |
|---|---|---|
| **前頭前野** | 言うかどうかの判断・抑制 | 条件が揃うと必ず発話する＝反射的。ただし人間も12ヶ月では抑制課題の正答率が54%（ほぼ偶然）なので、月齢としては不自然ではない |
| **視覚野** | 見えから物を認識する | DINOv2 で代用。太郎の経験では育たない（逸脱リスト その23） |
| 運動前野 | 動作の準備 | 未検討 |
| 頭頂葉の一部 | 空間の把握 | 未検討 |

## 5. あるが使われていないもの

| もの | 状態 |
|---|---|
| GRU の隠れ状態（文脈） | 発話のたびに `hidden=None` でリセット。文脈が残らない |
| GRU の行動生成 | 体が固定（座位・pin_joints）なので出番がない |
| 周辺視 | 視線を動かすためだけ。意味の判断に使っていない |
| 右目 | 2026-08-30 に認識を片目にした（両目と成績が同じだったため） |
| 恒常性の報酬 | `body/homeostasis.py` にあるが脳から呼ばれていない（呼び出し0件） |
| 目標指向の探索 | `goal_babbling/` にあるが既定OFF（「現状は有害と判明」） |

## 6. 移行のときの注意

- **import が壊れる**。`from brain.lexicon import ...` のような参照が各所にある
- 移動は1つずつ行い、その都度 `run/main.py` が起動するか確認する
- `taro_brain.py` は名前を変えると影響が大きい（チェックポイントの復元にも関わる）
- **モデルの保存・復元と噛み合うか**を必ず確認する（クラス名や属性名が変わると
  既存の `.pt` が読めなくなる可能性がある）
