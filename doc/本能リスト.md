# 太郎の本能リスト（プロジェクト全体）

太郎に与えた「生得の本能」と「生まれつき持つ身体・脳の部品」の一覧。発達（目標A→B→…）を通じて累積する。各項目に人間での根拠・実装場所・導入した目標・有効段階を記録する。

太郎の中身は**本能のみ**（答え・ラベルは注入しない）という設計哲学に基づく。ラベル凡例：【人間模倣】＝人間の仕組みに対応、【既存AI研究】＝工学的手法。

## 眼球運動の保持成分（pulse-stepのステップ・神経積分器相当）2026-08-18

- **何か**：サッケードで動かした先に視線を保持し続ける持続的な筋活性。動き信号が
  0.5秒途切れると解除。`orienting_hold`（既定OFF）
- **人間側の根拠**：pulse-step神経支配（Robinson 1975）。脳幹の神経積分器が
  眼球位置の保持信号を作る。位置+速度のフィードバック（PD）で実装
  （P単独では共振して保持できないことを実測で確認）
- **前提**：眼球の受動弾性（中央復帰バネ）と筋力較正（eye_muscle_scale）とセットで意味を持つ
