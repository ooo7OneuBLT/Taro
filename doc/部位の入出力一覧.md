# 部位の入力と出力 —— 太郎の中で何がどこへ渡されるか

作成 2026-09-03。ユーザーの要望「それぞれの部位の入力と出力だけは把握しておきたい」。
実際のコードの関数の引数と返り値から書き起こしたもの（推測ではない）。
機構の全体像は `doc/脳の地図.md`、配線の図は `run/wiring_map.py` と `run/tools/wiring.py`。

---

## 言語（目標F）で実際に通る道

| 部位 | 置き場所 | 入力 | 出力 |
|---|---|---|---|
| **目** | `senses/vision_backends.py` `encode()` | 左目の画像・右目の画像（224×224） | **384個の数字**（見た目の要約） |
| **耳** | `senses/`（hearing） | 親の発話（音の記号の列） | 音の記号の列 |
| **言葉の脳（GRU）** | `brain/cerebral_cortex/recurrent_core.py` `forward_hidden()` | 音の記号の列／前の隠れ状態／体の内部状態／**見た目の384個**（先頭に1個ぶん足す） | 次の隠れ状態 → 次の音の確率 |
| **語彙の表** | `brain/.../temporal_lobe/lexicon.py` `observe()` | 音の記号の列・各位置の確信度・そのときの状態・**終わりの確率** | 切り出した語の単位（分節の結果） |
| **見た目の記憶** | 同上 `observe_view()` | 見た目の384個 | 語ごとの平均ベクトル（`proto`・25件） |
| **海馬** | `brain/language_hippocampus/` | 語と見た目の組 | 直近の記憶・睡眠時の呼び出し |
| **定位反射** | `brain/midbrain/orienting.py` `update()` | 目の画像1枚 | 動きの地図・目立ち度の地図・次に見る場所 |
| **言う確率の門** | `brain/subcortical_nuclei/speech_gate.py` `decide()` | 乱数 | 言う／言わない |
| **学習進度** | `brain/drives/learning_progress.py` `update()` | **予測誤差 1つの数値** | 進み具合（遅い平均 − 速い平均） |

## 実測でわかっている接続の穴（2026-09-03時点）

| 部位 | 状態 |
|---|---|
| 言う確率の門 | **実験ファイルに `produce.social` が無いので作られない**＝いま働いていない |
| 学習進度 | 運動の学習では使われるが、**言語には繋がっていない** |
| 恒常性の報酬 | 内臓（空腹・眠気・不快）は `hybrid=True` のとき存在するが、**報酬として脳に渡っていない**。しかも600歩で0.003しか動かない（時間の尺度が合わない） |
| GRUの隠れ状態 | 発話のたびに `hidden=None` でリセット＝**文脈が残らない** |
| 動きの向き | 動きの「強さ」だけ。**向きを持たない**（2026-09-03に下見で成立を確認、未実装） |
| 前頭前野 | **無い**（目標を保持する・注意を配分する・言うのを抑える） |
| 頭頂葉の一部 | **無い**（空間の把握） |
| 物体の同一性追跡 | **無い**（さっきのコップと今のコップが同じ物、という認識） |

## 読み方の注意

- 「予測誤差1つの数値」は運動の話。**言語で何を誤差とするかは未決**（候補：見たものの名前の確信度／聞いている音の予測誤差）。
- 見た目の384個は DINOv2 という既製の部品が出す。**太郎の経験では育たない**（逸脱リスト その23）。
- 語彙の表は音の記号の列を鍵にして、見た目の記憶を値に持つ。**「新しさ」はこの記憶との距離で測れる**が、既知0.29 vs 未知0.41 と分布が重なり、物差しとしては弱い（F2-58b）。
