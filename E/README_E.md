# 目標E：運動発達（自発運動 → 目的的運動 → 歩行）

太郎の**運動（粗大運動）の発達**を、人間の乳児の順序で育てる段階。自発運動から始まり、その**終了（目的的運動への移行）**を経て、座位・這い這い・歩行までを扱う。

> **用語について（2026-08-13統一）**：以前はこの現象を「運動性喃語（motor babbling）」と
> 呼んでいたが、調査の結果この語は乳児発達研究（発達心理学・臨床発達運動学）の標準用語ではなく、
> 主にロボット工学・機械学習の分野で使われている用語だと判明した（詳細は
> `doc/文献調査/` の 2026-08-13「乳児の運動発達順序の外部文献確認」（非公開）
> B-5節）。そのため2026-08-13以降、記録では「自発運動」に統一する。過去の日誌
> （`E/docs/研究日誌.md`等）の記述は原本のため書き換えていない。

## なぜ独立の目標か（＝依存関係）
[発達依存関係マップ](../doc/発達依存関係マップ.md)により、運動発達は**C（自己モデル）とD（他者理解）の"土台"**と判明：
- 自己モデル(C)は自発運動が育てる（Hadders-Algra 一次変動性）
- D（動く自分での視覚的他者理解＝egomotion）は、**自発運動の終了＋自己運動の割り引きが前提**
- ＝運動発達を飛ばしてDをやったのがDの壁の原因。だからDの前提として運動発達を独立目標に切り出した。

> 注意：文字「E」は**識別子**であり発達順ではない。依存関係では**運動発達はC・Dより"前"の土台**。

## スコープ（[運動発達ロードマップ](../doc/運動発達ロードマップ.md)の8段階、詳しい月齢・個人差は[運動発達ロードマップ_詳細版.md](docs/運動発達ロードマップ_詳細版.md)を参照）
自発運動(0-2m) → 頭部制御 → リーチング（動き始め） → 寝返り → 座位 → 這い這い → つかまり立ち → 歩行(12-18m)。
**最初のマイルストーン＝「自発運動の終了（目的的運動への移行）」**（一次変動性→二次変動性、
Hadders-Algraの神経群選択説＝NGSTに基づく。NGSTは発達運動学の唯一の定説ではなく、著者自身が
ダイナミックシステム理論＝DSTと並ぶ2つの主要枠組みのうち採用した立場である。詳細は
[運動発達ロードマップ_詳細版.md §0-b-5](docs/運動発達ロードマップ_詳細版.md)参照）。

**「リーチング」の定義（2026-08-13決定）**：太郎の計画で「リーチング」と言うときは、
**物に向かって手を伸ばそうとする意思をもって命令を送るところ**を指す。結果として実際に
物へ届かなくてもよい（＝「動き始め」であって、狙って正確に届く「完成形」ではない）。
外部文献では、この「動き始め」は生後3〜4ヶ月ごろに出始めるとされる一方、狙って正確に
届けられるようになる「完成形」は生後6〜15ヶ月かかるとされる（Hadders-Algra 2018、
上記文献調査B-2節）。

**重要な気づき（2026-08-13）**：この定義に立つと、8段階の1番目「自発運動の終了
（目的的運動への移行）」と、3番目「リーチングの動き始め」は、**実質的に同じ現象**を
指している。どちらも「目的を持って手を動かし始める」ことを指す言い方の違いにすぎない
（「自発運動の終了」＝「目的的運動への移行」＝「リーチングの動き始め」）。8段階の並びは
変えないが、1番目の終わりと3番目の始まりが同じ現象であることを、混乱を避けるため
ここに明記する。

間に挟まる「頭部制御」については、リーチングには姿勢の制御（頭部・上部体幹の安定した
参照枠）が前提として要ることが、複数の一次資料で共通して挙げられている（上記文献調査
A-3節）。ただし「首がすわっていることが必須」という直接的な表現は原文には無く、より広い
「姿勢制御全体の向上」という前提として書かれている点に注意（外部支持があれば首すわり前
でもリーチが出現しうる、という設計上の扱いは[運動発達ロードマップ_詳細版.md](docs/運動発達ロードマップ_詳細版.md)
の段階2にも既に反映されている）。

**注意（2026-08-13追記）**：Hadders-Algra原文によれば、一次変動性→二次変動性の移行時期は
機能ごとに大きく異なる（機能特異的年齢）。「自発運動の終了」に近い姿勢調整・粗大運動レベルの
移行は生後3ヶ月以降に始まるが、**リーチングという機能に限れば、この移行の完成（二次変動性の
確立）は生後6〜15ヶ月かかる**（Heineman et al. 2010、Hadders-Algra 2018原文で確認）。
「0〜2ヶ月で自発運動が終わり、即座にリーチングが完成する」という理解は原文の数値と
食い違う。上記マイルストーンは「大まかな移行の始まり」を指すもので、「リーチングの完成」を
指すものではない。

なお「リーチングと寝返りの前後関係」は、一次文献では直接確認できなかった（リーチングの
動き始め＝生後3〜4ヶ月、寝返りの中央値＝4.5ヶ月〈AIMS規範データ、Tier2〉と時期が近接して
おり、どちらが先かを積極的に支持する強い根拠は見つからなかった。詳細は上記文献調査を参照）。

詳細は
`doc/文献調査/` の 2026-08-13「乳児の運動発達順序の外部文献確認」（非公開）参照。

## 哲学（太郎と整合）
各段階を**スクリプトせず**、**体年齢（成長モジュール）＋態勢＋環境（足場）**を与えて、同じ本能（予測誤差最小化・好奇心・強化学習・睡眠リプレイ）で運動が創発するかを見る。判定は**動画目視＋物理指標（jerk等）**。

## C・Dとの関係
- **C（自己内部モデル）**：運動発達が育てる。C5（自発運動の質・progress報酬でmean\|jerk\| 65%減）はここに接続。
- **D（他者理解）**：運動発達＋egomotion割り引きが済むまで**"待ち"**。
