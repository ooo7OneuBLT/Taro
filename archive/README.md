# archive — 退避したコード

太郎の走行から外したが、**捨てていない**コードの置き場。

## 置き場所の決まり

- 目標フォルダ（`A/`〜`F/`）の外に置く。特定の目標に属さないため
- `taro_core/`（＝太郎そのもの）の外に置く。走行では使わないため
- `doc/` にも置かない。`doc/` は文書の置き場で、コードの置き場ではない

## 1ファイルに必ず書くこと

1. **なぜ外したか**（実測の数値つき）
2. **外した中身**が何をするものか
3. **人間側ではどうなっているか**（人間模倣として不要になったのか、太郎の都合で外しただけなのか）
4. **元の場所**（ファイルと、外した時点のコミット）
5. **戻すときの条件**

「使っていないから消した」だけでは、後から読む人が
「もう要らないもの」なのか「まだ要るが今は外してあるもの」なのかを判断できない。
